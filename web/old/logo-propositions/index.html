Empreinte,
en huit marques.

Une planche pour une app de CV politiques factuels et sourcés. Chaque piste est pensée comme un système vivant dans l’interface, pas comme une icône décorative.

Étude / 08.08.2026 — encre #14151A, papier #F7F6F4, signal #DFFF00 · Manrope uniquement

01
EmpreinteRegistre ouvert

Le registre actif

Une ligne de dossier traversée par un point de preuve. Le trait peut se remplir à mesure qu’une source est vérifiée, donnant à la marque une grammaire naturelle de progression et de traçabilité.

État : ligne qui se complète
02
EmpreinteL’arc civique

L’arc civique

Un hémicycle réduit à une courbe de données : plusieurs voix, une structure lisible. Les points signal peuvent s’allumer, se regrouper ou changer de densité dans les vues de groupes et de votes.

État : sièges qui s’allument
03
EmpreinteLa trajectoire

La trajectoire

Une donnée devient un parcours, avec un point d’arrivée net. Cette marque porte le récit chronologique d’un mandat et peut tracer les étapes d’un dossier sans suggérer une performance ou un classement.

État : tracé étape par étape
04
EmpreinteLe dossier probant

Le dossier probant

La forme d’un dossier se distingue par sa coupe et son signal de validation — jamais une coche générique autonome. Elle affirme une méthode : un fait est montré parce qu’il est relié à sa source.

État : sources validées
05
EmpreinteLa case source

La case source

Une grille éditoriale où une cellule devient active : le fait trouvé dans le vaste ensemble. La marque installe un langage de cartes, filtres, tables et sélections, très produit sans devenir fintech.

État : cellule sélectionnée
06
EmpreinteLe point commun

Le point commun

Des lignes indépendantes convergent vers une même pièce vérifiable. C’est la métaphore d’une information croisée, d’un vote collectif ou d’une voix individuelle située dans un ensemble.

État : lignes qui convergent
07
Empreintepolitique

Politique

Deux arcs et une base composent un espace de parole sans dessiner une institution littérale. Sa symétrie donne un emblème mémorable, capable d’organiser les états « intervention », « texte » et « vote ».

État : arc intérieur actif
08
EmpreinteLe marqueur

Le marqueur

Un curseur vertical pose une position précise dans un registre horizontal. Minimal mais propriétaire, il exprime la consultation active : retrouver un fait, naviguer dans le temps, garder la preuve à portée de vue.

État : curseur qui navigue
